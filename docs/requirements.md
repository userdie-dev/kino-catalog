# Требования к проекту

Каталог фильмов и актёров на базе Nuxt 4 + Nuxt UI 4, данные — из TMDB API
(через `tmdb-js-wrapper`, запросы проксируются через `server/api/*`, чтобы не
светить API-ключ на клиенте — см. существующий `server/api/movies/popular.get.ts`).

Интерфейс — на русском языке (см. текущую главную страницу).

## Страницы

### Главная (`/`)

Несколько тематических подборок (блоки/карусели), каждая — превью списка с
переходом «показать все» на соответствующую страницу списка (с нужным
табом/режимом):

- Популярные фильмы
- Фильмы с высоким рейтингом
- Популярные актёры

### Список фильмов (`/movies`)

- Переключатель режима: **Популярные** / **Топ рейтинга**.
- Поле поиска по названию — при непустом запросе список заменяется
  результатами поиска (TMDB search/movie), переключатель режимов при этом
  скрывается/неактивен.
- Постраничная навигация (используем уже поддерживаемый параметр `page` в
  TMDB-запросах).
- Сетка карточек фильма: постер, название, год, рейтинг (как на текущей
  главной) — карточка ведёт на страницу фильма.
- Состояния загрузки и ошибки — по образцу текущей главной (спиннер,
  `UAlert` с кнопкой «Повторить»).

### Страница фильма (`/movies/:id`)

- Шапка: постер, название, дата выхода, жанры, рейтинг.
- Описание (overview).
- Актёрский состав и съёмочная группа: список актёров (фото, имя, роль) со
  ссылками на страницы актёров; из группы — как минимум режиссёр.
- Похожие фильмы — блок/карусель со ссылками на их страницы.
- Трейлер — если у TMDB есть видео для фильма, встраиваем плеер; если нет —
  блок не показываем.
- Состояния загрузки и ошибки — как на остальных страницах.

### Список актёров (`/actors`)

- Переключатель режима: **Популярные** / **Лучшие**.
  ⚠️ У TMDB нет отдельного эндпоинта «top rated» для персон (в отличие от
  фильмов) — на этапе реализации нужно решить, как формировать список
  «Лучшие» (например, своя сортировка по популярности/известным работам).
  Отметить как открытый технический вопрос.
- Поле поиска по имени — при непустом запросе список заменяется результатами
  поиска (TMDB search/person).
- Постраничная навигация, аналогично списку фильмов.
- Сетка карточек актёра: фото, имя — карточка ведёт на страницу актёра.
- Состояния загрузки и ошибки — по общему образцу.

### Страница актёра (`/actors/:id`)

- Шапка: фото, имя, дата рождения.
- Биография.
- Фильмография — список фильмов, в которых актёр снимался, со ссылками на
  страницы фильмов, отсортированный по дате.
- Состояния загрузки и ошибки — по общему образцу.

## Сквозные требования

- Запросы к TMDB выполняются напрямую со страниц через `tmdb-js-web`
  (`app/utils/tmdb-client.ts`, `TMDBWebAPI` с `accessToken`) — без серверного
  прокси. Библиотека работает на нативном `fetch` (в отличие от
  `tmdb-js-wrapper`, который Node-only и не может выполняться в браузере) и
  поддерживает v4 Read Access Token (Bearer) напрямую, что и требовалось для
  используемого ключа. ⚠️ Осознанное отступление от исходного требования
  прятать ключ на сервере: ключ лежит в `runtimeConfig.public.tmdbApiKey`
  (`NUXT_PUBLIC_TMDB_API_KEY`) и виден в клиентском бандле/сетевых запросах.
  Все запросы идут с `language: 'ru'`.
- Общие типы (`Movie`, `Actor`, состав, фильмография и т.д.) — в
  `shared/types/`, по аналогии с текущим `movie.d.ts`.
- UI — компоненты Nuxt UI (`UPageHero`, `UPageSection`, `UCard`, `UAlert`,
  `UBadge`, `UIcon` и т.д.), единый стиль с текущей главной.
- Адаптивная сетка для списков (как в текущей реализации: 2/3/4/5 колонок в
  зависимости от ширины экрана).
- Единообразная обработка состояний загрузки/ошибки на всех страницах.
